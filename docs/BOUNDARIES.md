# Boundaries and non-claims

DIKWP-MESH² is a semantic research prototype.

It does not:

- prove an observer-independent metaphysical definition;
- certify life, consciousness, personhood or legal status;
- treat semantic consensus as scientific truth;
- authorize deletion of minority or incompatible perspectives;
- allow Purpose to act as an unreviewable global controller;
- install new semantic dimensions without tests and rollback conditions;
- substitute for scientific, legal, clinical or ethical review.

The system's “subjectivity escape score” measures reduced dependence on one observer. It is not a truth score.
